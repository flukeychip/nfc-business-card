# Alexander Arens — NFC Business Card Landing Page

Landing page served when someone taps the NFC PCB business card.
Single self-contained `index.html`, deployed via GitHub Pages.

Styling intentionally mirrors the main portfolio (accent `#0057B8`, Inter /
JetBrains Mono) so the card and the portfolio read as one identity.

Lives inside the Portfolio folder locally for convenience, but is a fully
separate git repo — the portfolio `.gitignore` excludes it, and
`scripts/sync-assets.ps1` skips it.
